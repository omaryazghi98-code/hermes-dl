Orbit Store / Orbit Zero

Port 34177

Orbit Store runs on the PS5. Open its local browser interface to pair using the six-digit code shown on the console. Orbit Zero is the companion PC application for downloading on the computer and transferring over the LAN.

Orbit's UI is opened in the integrated browser. Hermes does not automate or bypass Orbit's pairing code.

PS5Upload

Engine :19113

PS5Upload handles resumable transfers, package installation and console file management. Hermes checks the engine and console status, then opens the official client you already have installed.

Keep the engine on this PC and on your trusted network. Its API can modify console files and does not provide its own password protection.

FTP / remote file browser

Passive FTP
Connect to a PS5 FTP server you have enabled (PS5Upload documents port 2122 for its optional server). Passwords are used only for the current request and are not saved by Hermes. FTP is unencrypted, so use it only on a trusted LAN; passwords are not encrypted in transit. Prefer PS5Upload for large or sensitive transfers. The remote browser offers copy transfers only; it will not delete or overwrite remote files.
